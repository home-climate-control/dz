Home Climate Control: v4.5.0. Release Notes
==

Release focus: HCC WebUI grows meat on its bones

## Bugfixes and enhancements
* Bugfix: WebUI metadata URL returns metadata, not a list of one metadata.
* Bugfix: [#333](https://github.com/home-climate-control/dz/issues/333) - sensor departures are now handled correctly for this corner case.
* Enhancement: [#347](https://github.com/home-climate-control/dz/issues/347) - it is now possible to fine-tune the split between the HVAC unit and the economizer.
