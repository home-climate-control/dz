# last-imperative-maintenance branch

## BIG FAT WARNING
TL;DR: [go here](https://github.com/home-climate-control/dz?tab=readme-ov-file#home-climate-control).

> You are looking at the obsolete version of the code.

> The only reason to keep it alive is that newer versions of the code don't build on Raspberry Pi 3B - not enough memory.

> The only two reasons to run this code, given the fact that the difference between Pi 3, 4, and 5 prices are negligible
> compared to their lifetime, are:
> * When you are severely constrained by heat output. Still, if this is a concern, you probably need to reconsider your strategy.
> * If you are using 1-Wire or XBee sensors and/or actuators ([submit a request](https://github.com/home-climate-control/dz/issues)
>   if this is the case, it hasn't been migrated for lack of demand).

> Please consider using the [current version of the code](https://github.com/home-climate-control/dz?tab=readme-ov-file#home-climate-control),
> it contains much more features, is more stable, and is documented better.
