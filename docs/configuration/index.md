## DZ3 Configuration Guide
It's a shame, but it looks like the complete configuration guide for legacy configuration was lost to bit rot.
As a recourse, please browse through https://diy-zoning.blogspot.com/search/label/configuration or
[submit a request](https://github.com/home-climate-control/dz/issues), should the information below prove insufficient.

## When in doubt, use Spring
If you feel gaps in above documents, you're probably right. Go take a look at the source code and apply common sense and [Spring IoC container](http://docs.spring.io/spring/docs/2.5.x/reference/beans.html) configuration guidelines, and you're likely to enable advanced functionality that is present, but not yet documented.
